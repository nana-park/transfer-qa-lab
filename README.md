# 송금 QA 실습

B 흐름으로 고정된 가상 송금 실습입니다. 실제 송금은 없으며 실제 개인정보를 입력하지 마세요.

- before/: 연속 클릭 문제가 있는 기준본
- after/: 완료 화면 전환 뒤 이어지는 다중 클릭이 처음으로 버튼을 실행하지 않도록 수정한 버전

가상 정보: 김하늘 / 하늘은행 / 000-1234-5678 / 30,000원. 다른 계좌와 금액을 거절하는 것은 수업 정책입니다.

각 버전의 초기화는 해당 QA 버전의 sessionStorage 키만 지웁니다. 기존 A/B 실험 상태는 건드리지 않습니다. 분석 SDK나 결과 전송은 없으며 선택적 결과 다운로드는 로컬 JSON 파일입니다. 호스팅 제공자의 일반 접속 처리는 별개입니다.

동일 TC: 정상 정보를 입력한 뒤 보내기를 빠르게 두 번 클릭합니다. 기대 결과는 완료 화면 유지와 완료 이벤트 한 번입니다. before는 화면 유지에 실패하고 after는 통과합니다.
